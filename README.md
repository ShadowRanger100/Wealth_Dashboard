💰 Wealth Compass – Personal Finance & Wealth Analytics Dashboard
🔍 Problem Statement

Tracking income, spending, and financial behavior across multiple categories and merchants can quickly become overwhelming. This dashboard provides a structured view of personal finance data to help users understand spending patterns, income trends, and overall financial health.

📊 Key Insights

Spending shows significant month-over-month volatility, indicating irregular expense patterns.

A small number of merchants contribute a large portion of total spending, suggesting opportunities for cost control.

Income is heavily concentrated in a primary source, highlighting potential financial dependency risk.

Monthly trend analysis enables early identification of overspending periods.
